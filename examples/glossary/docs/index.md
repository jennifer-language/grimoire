# A Book With Words In It

The outline of this book is three chapters long, and the second one mentions the
outline again without linking it: only the first use on a page is linked, because
a page where every mention is blue is a page nobody reads.

A term inside `code` is left alone - `outline` there is the thing, not the word
for the thing - and so is one inside [a link that already exists](guide/building.md).

```sh
# the outline in a fence stays a fence
grimoire build
```
