# What is left alone

A colon is punctuation long before it is markup, and a book is full of them:

- `Note: a thing` keeps its colon
- `at 10:30 sharp` is a time
- `a 3:2 ratio` is a ratio
- `std::vector` is a type
- `https://example.com` is a URL

A name the table does not know is left as written - `:nosuchcode:` - rather than
guessed at, and a fence is left alone entirely:

```markdown
Ship it :rocket:
```

The printable book is the one thing to check before turning this on: it draws
what its fonts carry, and an emoji reaches the page as whatever
`TRANSLITERATIONS` says, or as a question mark if it says nothing.
