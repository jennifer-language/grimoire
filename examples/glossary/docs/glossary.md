# Glossary

The headings below are the terms. Adding one here starts linking it on the next
build; renaming one stops. Nothing on this page is linked to itself.

## Outline

The order of the book, as `SUMMARY.md` gives it.

## Search index

What the search box reads: one record per section, written beside the pages.

## Deck

A directory of Jennifer modules with a `deck.toml`, which is how Grimoire itself
is published.
